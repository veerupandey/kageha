# Getting started

Use this when someone asks how Kageha works or needs help getting started. Point them to the [quick start](https://github.com/veerupandey/kageha#quick-start) and [usage guide](https://github.com/veerupandey/kageha/blob/main/docs/USAGE.md).

- Connect a model in **Settings → Models** and select it in the composer.
- Use ordinary chat for requests and follow-ups. Use `/plan` to review a plan before selecting **Build**, or `/goal` to work toward a saved objective.
- Attach files to the chat and open generated artifacts in **Files**.
- Use **Browser** for private browsing and human takeover. Use the execution picker for a Docker workstation or configured SSH host. The native macOS helper has its own setup and permissions.
- Use **Extensions** for skills, plugins, and MCP connections. Choose **Ask** permissions when you want to review sensitive actions before dispatch.
